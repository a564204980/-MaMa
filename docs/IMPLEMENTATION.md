## 已执行的验收

1. TypeScript 无类型错误，Rollup 微信产物构建成功。
2. 20 个固定种子一致性和交互点真实碰撞路线测试。
3. 第一夜从出生到收集、调查、封门、撤离的完整自动模拟。
4. 红绳单次消耗、封对/封错/超时、3 秒家人及追逐预警、分数界限测试。
5. 微信双触点分发与 touchcancel 释放测试。
6. 浏览器桌面与 844×390 横屏视觉检查、控制台错误检查。

## 美术验收记录

图片由独立 agent 生成，主 agent 已亲自查看标题背景并验证叠字：左侧深色留白可用；右侧卧室和婴儿房冷暖光明确；没有生成文字、血腥或常驻怪物。标题图比户型图更写实，因此只用于标题页。角色仍是占位绘制，不能视为正式角色资产验收通过。

## 建议下一轮顺序

先在微信开发者工具和 Android/iOS 真机完成移动/触摸/音频测试；再校准视野、手机字号、门位与节奏，逐步拆分当前玩法类；之后接 PixiJS 和正式角色资产、家庭规则、第五夜及平台服务。平台能力的版本、包体限制和审核规则应以接入当时官方文档为准。

## 首页方向修正
启动配置恢复 portrait；首页与首页设置采用 390×844 竖屏布局，既有标题图按比例裁切复用。游戏保持 1280×720 横屏设计，竖屏运行时旋转画布并逆变换触摸坐标，返回首页恢复竖屏。已在 390×844 浏览器验证进入游戏、旋转后暂停、返回首页、首页设置的点击命中。微信开发者工具需重新编译加载 game.json；硬件方向和安全区仍需真机检查。

## 摇杆与家人显示修复
保留 1.8 倍地图与平滑跟随镜头。输入以手势来源归属去重，触点编号使用空值合并以保留 0；松手可使用缓存位置，补齐 touchcancel、pointercancel、失去捕获和失焦释放。移除点击时的调试 Toast，保留坐标日志。父母睡眠时绘制在双人床上，醒来使用原有 AI 位置；婴儿绘制在婴儿床内。角色继续采用代码绘制。
新增 npm run test:controls，验证四向摇杆更新、混合输入去重、无坐标松手、松手静止、双指独立、取消事件及家人绘制调用。已有种子、完整通关、微信首页输入测试均通过；未据此宣称真机手感验收完成。
