# 疯狂爸妈：玩法与角色调整

2026-09-09，依据用户最新要求。本文件是新方向记录，不能当作已实现功能清单。

## 已确定

- 游戏名改为《疯狂爸妈》。不再以找异常、识别第五人、线索互证和红绳封印为核心。
- 玩法围绕女孩、噪声、父母苏醒追赶、躲藏与回床装睡展开。参考用户提供的《疯狂妈妈》截图与说明；未获得完整规则，不声称完整复刻。
- 角色以用户最新全家设计图为准：圆短身体、短小脚，保持父母的新表情，女孩睡衣更可爱。
- 首先单独设计女孩。需要向右、向前、向后奔跑；左向可在没有方向性饰品要求时镜像右向。
- 头发和身体为完整主体；手臂使用完整手臂独立层，不拆成上臂、前臂多节拼接。
- 携带物品时双手空手上举，人物图片不含任何物品或占位物。物品后续由代码独立绘制在角色头顶。奔跑和持物需要可区分的姿势。
- 素材由独立图片 agent 生成，主 agent 检查造型一致性、遮挡、方向、动作可读性后再接入。

## 待确定

- 单局胜利目标：捣蛋任务、物品运送或坚持到天亮。已向用户询问，回答前不擅自重写任务流程。
- 爸爸与妈妈的追逐差异、物品清单及关卡节奏，在目标确定后细化。

## 代码现状

Run.ts 第一夜已有送三件安抚物、父母查床、呼吸检查、三次被抓结束；第二夜起仍有异常与第五人逻辑。MainGameScene.ts 有对应调查、封门与结算界面。改名不等于玩法迁移完成。

保留用户手绘碰撞与门位置。新的角色造型稿不直接覆盖运行中的素材。
