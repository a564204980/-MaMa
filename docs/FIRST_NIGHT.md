# 第一夜：安抚全家

第一夜采用独立教学循环，第二夜及后续每日挑战继续使用调查、封门和追逐。

- 一次携带一件安抚物，送到婴儿床后才能再拿。
- 每次提交降低哭闹30点、恢复父母睡眠12点，并增加25%睡意。
- 送齐三件、婴儿哭闹低于40且父母都在睡眠状态时，回自己的床，每秒增加5%睡意；达到100%通关并解锁第二夜。
- 可以提前回床装睡，但未送齐三件不能获得睡意。
- 父母睡眠低于70显示翻身，低于45进入坐起预警，3秒后下床。
- 被抓送回床边、扣10%睡意，已获得物品保留。三次被抓或300秒超时结束。
- 婴儿哭闹仍受时间、近距离噪声、物品提交和长按安抚影响。
- 第一夜隐藏调查与封门入口，结算不揭示异常身份，只用额外呼吸提示第二夜。

本轮验证包含完整三次送物后回床胜利、提前装睡不能胜利、超时失败、近距离噪声及后续夜晚的封门追逐回归。自动路线不代表真实玩家时长；节奏与吸引力仍需手机试玩。
