# 碰撞编辑器

在项目目录运行 `npm run editor`，打开 http://127.0.0.1:4174 。这是电脑端本地编辑工具，不会打进微信小游戏。

1. 红色区域是墙，橙色区域是家具。背景使用游戏同一张图片和 1580 × 996 世界坐标。
2. 画矩形：按下拖动，松开完成。画多边形：逐点点击，Enter 或点击起点闭合。
3. 选择模式中，拖动区域内部移动，拖动白色顶点改形状。矩形保持直角。重叠区域从列表选择。
4. 滚轮缩放；空格加拖动或中键拖动平移；完整背景按钮恢复全图。
5. 检查通行显示人物 20 × 20 的碰撞范围。绿框可走，红框被阻挡，底部解释原因。显示地图外边界可辅助辨认整张地图的边缘。
6. 保存并构建游戏写入 `src/gameplay/collision-overrides.json` 并运行 Rollup。刷新游戏预览或在微信开发者工具重新编译后生效。

保存前会验证顶点范围和非共线性；允许边交叉或重叠，采用奇偶填充规则。上一版文件备份在 `.work/collision-overrides.previous.json`；导出备份按钮可以另外下载 JSON。页面支持撤销/重做和离开时未保存提醒。

编辑对象为墙与家具的阻挡区域。门口虚线是动态门参考，不是墙。已取消旧房间地面范围限制；未画阻挡的地方可以通行，只保留整张地图外边界及关闭的动态门。父母寻路与玩家移动使用同一份新碰撞数据。运行 `node scripts/test-collision-editor.mjs` 验证多边形碰撞与原有矩形的兼容性。
