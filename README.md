# 疯狂妈妈MaMa (-MaMa)

基于微信小游戏开发规范与全套玩法机制的《疯狂妈妈MaMa》完整项目。保留 TypeScript + Rollup + Canvas 2D 框架与极致手感。


## 运行

```sh
npm run type-check
npm test
npm run build
npm run preview
```

浏览器访问 http://127.0.0.1:4173 。先构建再预览，修改源文件后需要重新构建（也可运行 `npm run dev`）。

微信开发者工具导入项目根目录，工程配置已指向 `dist/`，启动首页默认竖屏，首页设置页同为竖屏。进入游戏后画布按横屏方向绘制，竖持设备时请横握手机；返回标题页恢复竖屏排版。渲染旋转和触控逆变换由场景统一处理，不依赖运行时动态转屏 API。AppID 沿用项目现有配置。浏览器预览用于玩法和界面检查，微信真机表现需要单独测试。

## 怎么玩

- 左侧摇杆控制移动，轻推慢走，推满快速移动；键盘 WASD / 方向键移动，Shift 慢走。
- 右侧情境按钮或 E 交互。短按拾取、调查、开关门；长按轻开门、持续安抚。在藏身处长按屏息，松开恢复耐力，短按离开。
- 寻找奶瓶、小熊、小毯子，带回婴儿床。第一夜位置固定，后续夜晚按种子分散放置。
- 靠近镜面、监控、婴儿房听声点和餐桌调查，Q 打开证据板。记录本会暂停探索。
- 至少两条证据后，靠近目标房门，按 R 选择封门。红绳只能使用一次。
- 封对后去玄关或回床撤离；封错或觉醒归零后，3 秒预警接 20 秒追逐，途中无法打开暂停/证据窗口。F 使用一次遥控器引开追踪。
- 结算可立即重开。正确封门并撤离后解锁下一夜，当前原型提供四夜；第五夜尚未开放。

第一夜提示：卧室小熊旁有奶瓶，厨房与电脑房各有一件安抚物。注意镜子、监控和声音所描述的房间，记录不直接给出封门答案。

## 当前实现

固定九房间户型、家具碰撞、统一门位、客厅绕行路线与电脑房原有入口；多指触控、键盘与横屏缩放；噪声与闭门衰减；爸爸半醒/巡房、妈妈查床、婴儿哭闹/持续安抚；两种第五人模板、四处交叉线索、唯一红绳、正确撤离/错误追逐/超时/回床分支；六维 0–1000 评分、本地进度与最高分、第四夜上一局位置残影、北京时间每日同种子；关键提示和环境声音量、震动与提示设置；前后台暂停、清除按住状态、恢复遮罩。

音频是原创程序合成的原型提示，不是最终配音/空间混音。`scripts/audio.mjs` 可重建六个 WAV 文件。

## 验证

`npm test` 检查 20 组种子的确定性、全部交互点可达性（沿路线执行真实碰撞移动）、正确/错误封门、不可重复使用红绳、3 秒反应窗口、强制追逐与超时、分数边界、多触点与取消事件；另完整模拟第一夜三物品提交、两线索调查、封门和玄关撤离。自动最短路线用时约 52 秒，不能据此认定已达到文档的 5–8 分钟体验目标，仍需玩家试玩调速。

浏览器已检查标题、地图 HUD、证据板及 844×390 横屏尺寸，无控制台错误。未完成 Android/iOS 真机、低端帧率、来电、内存告警及微信提审测试。

## 代码入口

- `src/gameplay/House.ts`：共享户型、家具、门、碰撞及缓存导航网格。
- `src/gameplay/Run.ts`：纯玩法模型、种子、任务、睡眠、家人行为、证据、追逐、残影与评分。
- `src/scenes/MainGameScene.ts`：标题、游戏 HUD、操作、记录本、封门、设置和结算。
- `src/systems/SoundService.ts`：微信/浏览器短音效、距离衰减与句柄复用。
- `src/core/Engine.ts` / `InputManager.ts`：DPR、尺寸变化、多指触控、生命周期。
- `docs/IMPLEMENTATION.md`：文档对照和剩余工作。
